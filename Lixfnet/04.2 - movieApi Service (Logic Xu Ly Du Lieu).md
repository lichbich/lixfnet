## 🛠️ 1. Giới Thiệu `services/movieApi.ts`
Tệp `services/movieApi.ts` là lớp dịch vụ (Service Layer) chịu trách nhiệm:
1. Giao tiếp trực tiếp với máy chủ API của **Phim NguonC**.
2. Phân tích chuỗi thời lượng đa định dạng thành số phút nguyên.
3. Chuẩn hóa tên quốc gia, thể loại và từ khóa tìm kiếm tiếng Việt.
4. Chuyển đổi dữ liệu thô sang model `Movie` của ứng dụng.

## ⏱️ 2. Hàm Phân Tích Thời Lượng: `parseMovieDuration`

Dữ liệu thời lượng từ API NguonC rất đa dạng và không đồng nhất: *"1 giờ 45 phút"*, *"65 phút/tập"*, *"2h15m"*, *"118"*, v.v.

Hàm `parseMovieDuration` sử dụng Regular Expressions để nhận diện chính xác 3 mẫu:

```typescript
export function parseMovieDuration(
  timeStr?: string,
  isSeries?: boolean
): { durationStr: string; durationMinutes: number } {
  if (!timeStr || !timeStr.trim()) {
    return {
      durationStr: isSeries ? '45 phút/tập' : '105 phút',
      durationMinutes: isSeries ? 45 : 105,
    };
  }

  const clean = timeStr.trim().toLowerCase();

  // Mẫu 1: "1 giờ 45 phút", "1g 45p", "2h15m"
  const hourMatch = clean.match(/(\d+)\s*(?:giờ|g|h)/);
  const minMatch = clean.match(/(\d+)\s*(?:phút|p|m)/);

  if (hourMatch) {
    const hours = parseInt(hourMatch[1], 10);
    const mins = minMatch ? parseInt(minMatch[1], 10) : 0;
    return { durationStr: timeStr, durationMinutes: hours * 60 + mins };
  }

  // Mẫu 2: "65 phút/tập", "115 phút", "24 min"
  if (minMatch) {
    return { durationStr: timeStr, durationMinutes: parseInt(minMatch[1], 10) };
  }

  // Mẫu 3: Dạng số thuần túy ví dụ "98"
  const numMatch = clean.match(/\d+/);
  if (numMatch) {
    const mins = parseInt(numMatch[0], 10);
    return { durationStr: `${mins} phút`, durationMinutes: mins };
  }

  return { durationStr: timeStr, durationMinutes: isSeries ? 45 : 105 };
}
```

## 🗺️ 3. Chuẩn Hóa Quốc Gia & Thể Loại

### 3.1 Bản Đồ Quốc Gia (`COUNTRY_NAME_TO_SLUG`)
Tự động ánh xạ các tên gọi khác nhau về một slug thống nhất:
- *"Hàn Quốc"*, *"Hàn"*, *"Korea"*, *"South Korea"* $\rightarrow$ `han-quoc`
- *"Mỹ"*, *"Hoa Kỳ"*, *"Âu Mỹ"*, *"USA"* $\rightarrow$ `my`
- *"Nhật Bản"*, *"Nhật"*, *"Japan"* $\rightarrow$ `nhat-ban`
- *"Việt Nam"*, *"Việt"* $\rightarrow$ `viet-nam`
- *"Trung Quốc"*, *"Trung"*, *"China"* $\rightarrow$ `trung-quoc`

### 3.2 Chuẩn Hóa Tìm Kiếm Không Dấu (`normalizeSearchText`)
Loại bỏ dấu tiếng Việt và chuyển ký tự `đ`/`Đ` thành `d` để người dùng gõ không dấu vẫn tìm ra phim chính xác:
```typescript
export function normalizeSearchText(str?: string): string {
  if (!str) return '';
  return str
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .replace(/[đĐ]/g, 'd')
    .trim();
}
```
