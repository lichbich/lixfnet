## 🛠️ 1. Giới Thiệu `services/movieApi.ts`
Tệp `services/movieApi.ts` là lớp dịch vụ (Service Layer) trung tâm chịu trách nhiệm:
1. Giao tiếp trực tiếp với hệ thống API của **KKPhim (`https://phimapi.com`)**.
2. Phân tách và chuẩn hóa hình ảnh từ CDN `https://phimimg.com` (`thumb_url` ngang 16:9 cho Hero/Player & `poster_url` dọc 2:3 cho Card).
3. Khai thác đồng thời cả đường dẫn IFrame Embed (`link_embed`) và luồng trực tiếp HLS Stream (`link_m3u8`).
4. Hỗ trợ tra cứu tức thì qua TMDB ID (`getMovieDetailByTmdb`).
5. Phân tích chuỗi thời lượng đa định dạng thành số phút nguyên.
6. Chuẩn hóa tên quốc gia, thể loại và tìm kiếm không dấu tiếng Việt.
7. Đề xuất phim tương tự thông minh (`getSimilarMovies`) theo quốc gia, thể loại và diễn viên chính.

## ⏱️ 2. Hàm Phân Tích Thời Lượng: `parseMovieDuration`

Dữ liệu thời lượng từ API rất đa dạng: *"1 giờ 45 phút"*, *"65 phút/tập"*, *"2h15m"*, *"118 phút"*, v.v.

Hàm `parseMovieDuration` nhận diện chính xác 3 mẫu:
```typescript
export function parseMovieDuration(
  timeStr?: string,
  isSeries?: boolean
): { durationStr: string; durationMinutes: number } {
  if (!timeStr || !timeStr.trim()) {
    return {
      durationStr: isSeries ? '45 phút/tập' : '105 phút',
      durationMinutes: isSeries ? 45 : 105,
    };
  }

  const clean = timeStr.trim().toLowerCase();

  // Mẫu 1: "1 giờ 45 phút", "1g 45p", "2h15m"
  const hourMatch = clean.match(/(\d+)\s*(?:giờ|g|h)/);
  const minMatch = clean.match(/(\d+)\s*(?:phút|p|m)/);
  if (hourMatch) {
    const hours = parseInt(hourMatch[1], 10);
    const mins = minMatch ? parseInt(minMatch[1], 10) : 0;
    return { durationStr: timeStr, durationMinutes: hours * 60 + mins };
  }

  // Mẫu 2: "65 phút/tập", "115 phút", "24 min"
  if (minMatch) {
    return { durationStr: timeStr, durationMinutes: parseInt(minMatch[1], 10) };
  }

  // Mẫu 3: Dạng số thuần túy ví dụ "98"
  const numMatch = clean.match(/\d+/);
  if (numMatch) {
    const mins = parseInt(numMatch[0], 10);
    return { durationStr: `${mins} phút`, durationMinutes: mins };
  }

  return { durationStr: timeStr, durationMinutes: isSeries ? 45 : 105 };
}
```

## 🗺️ 3. Chuẩn Hóa Quốc Gia & Thể Loại

### 3.1 Bản Đồ Quốc Gia (`COUNTRY_NAME_TO_SLUG`)
Tự động ánh xạ các tên gọi khác nhau về slug chuẩn của KKPhim:
- *"Hàn Quốc"*, *"Hàn"*, *"Korea"*, *"South Korea"* $\rightarrow$ `han-quoc`
- *"Mỹ"*, *"Hoa Kỳ"*, *"Âu Mỹ"*, *"USA"* $\rightarrow$ `au-my`
- *"Nhật Bản"*, *"Nhật"*, *"Japan"* $\rightarrow$ `nhat-ban`
- *"Việt Nam"*, *"Việt"* $\rightarrow$ `viet-nam`
- *"Trung Quốc"*, *"Trung"*, *"China"* $\rightarrow$ `trung-quoc`
- *"Ý"*, *"Italy"* $\rightarrow$ `y`

### 3.2 Chuẩn Hóa Thể Loại (`GENRE_NAME_TO_SLUG`)
- *"Hài"*, *"Hài Hước"*, *"Phim Hài"* $\rightarrow$ `hai-huoc` (trước là `phim-hai`)
- *"Khoa học viễn tưởng"*, *"Viễn tưởng"* $\rightarrow$ `vien-tuong` (trước là `khoa-hoc-vien-tuong`)
- *"Hành Động"* $\rightarrow$ `hanh-dong`
- *"Kinh Dị"* $\rightarrow$ `kinh-di`
- *"Chính Kịch"* $\rightarrow$ `chinh-kich`

## 🎬 5. Khai Thác Trailer Trực Tiếp Từ KKPhim (`trailer_url` & `extractYoutubeKey`)

KKPhim API cung cấp sẵn trường `trailer_url` (chứa URL YouTube chính thức của phim) ngay trong chi tiết phim:
1. **Hàm Bóc Tách YouTube ID (`extractYoutubeKey`)**:
   - Nhận diện mọi biến thể URL YouTube: `watch?v=...`, `youtu.be/...`, `embed/...`, `shorts/...` hoặc chuỗi key 11 ký tự thô.
   - Trả về mã định danh YouTube 11 ký tự chuẩn (ví dụ `3c68oabNkJs`, `P0ElxnFyfXY`).
2. **Tích Hợp Vào Cấu Trúc Đối Tượng `Movie`**:
   - `trailerUrl`: URL YouTube gốc từ KKPhim.
   - `trailerYoutubeKey`: Khóa YouTube đã bóc tách sẵn.
3. **Cơ Chế Phát Trailer Tức Thì (Zero-Latency Trailer Engine)**:
   - Cả 3 thành phần: `HeroBanner`, `MovieModal` và `HoverPopoutCard` đều kiểm tra `movie.trailerYoutubeKey` trước tiên. Nếu có sẵn, trailer phát ngay tức thì mà không cần tốn thêm bất kỳ request mạng nào.
   - Endpoint `/api/trailer` ưu tiên trích xuất `trailer_url` từ KKPhim trước khi phải dò tìm qua TMDB API, giúp tốc độ phát trailer mượt mà, chính xác và không phụ thuộc nhiều vào TMDB.
