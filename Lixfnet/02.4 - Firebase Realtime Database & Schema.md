## 📐 2. Mô Tả Chi Tiết Các Trường (Fields)

### 2.1 Bảng `lixfnet/users/{username}` (Hồ Sơ Người Dùng)
| Tên Trường | Kiểu Dữ Liệu | Bắt Buộc | Diễn Giải |
| :--- | :--- | :---: | :--- |
| `username` | `string` | Có | Tên tài khoản (được chuẩn hóa chữ thường không dấu) |
| `passwordHash` | `string` | Có | Mật khẩu đã băm bằng `bcrypt` (salt = 10) |
| `role` | `'admin' \| 'member'` | Có | Quyền hạn tài khoản |
| `displayName` | `string` | Không | Tên hiển thị thân thiện trên thanh Navbar |
| `createdAt` | `string` (ISO) | Có | Thời điểm khởi tạo tài khoản |
| `createdBy` | `string` | Không | Tên quản trị viên đã tạo tài khoản này |
| `updatedAt` | `string` (ISO) | Không | Thời điểm cập nhật gần nhất |

### 2.2 Bảng `lixfnet/users/{username}/myList/{slug}` (Danh Sách Phim Lưu Xem Sau)
Đồng bộ đám mây danh sách phim người dùng bấm dấu cộng (+) thêm vào để xem sau:
| Tên Trường | Kiểu Dữ Liệu | Bắt Buộc | Diễn Giải |
| :--- | :--- | :---: | :--- |
| `id` / `slug` | `string` | Có | Định danh định tuyến phim |
| `title` | `string` | Có | Tiêu đề phim |
| `posterUrl` | `string` | Không | Ảnh poster dọc |
| `backdropUrl` | `string` | Không | Ảnh bìa ngang |
| `addedAt` | `number` | Có | Mốc Unix Epoch (ms) khi bấm lưu |

### 2.3 Bảng `lixfnet/users/{username}/watchProgress/{slug}` (Tiến Trình Xem)
| Tên Trường | Kiểu Dữ Liệu | Bắt Buộc | Diễn Giải |
| :--- | :--- | :---: | :--- |
| `movieId` | `string` | Có | ID hoặc Slug của phim |
| `currentTime` | `number` | Có | Số giây người dùng đã xem được |
| `duration` | `number` | Có | Tổng thời lượng phim/tập tính bằng giây |
| `progressPercent` | `number` | Có | Tỷ lệ phần trăm đã xem (từ 0 đến 100) |
| `episodeTitle` | `string` | Không | Tiêu đề tập phim đang xem dở (ví dụ: "Tập 3") |
| `episodeEmbed` | `string` | Không | URL luồng phát của tập phim đó |
| `updatedAt` | `number` | Có | Mốc thời gian Unix Epoch (ms) khi xem |
| `episodesProgress`| `object` | Không | Bản đồ tiến trình chi tiết của từng tập phim |

## 🛡️ 3. Hàm Làm Sạch & Chuẩn Hóa Khóa: `cleanFirebasePayload`
Firebase Realtime Database có 2 nguyên tắc nghiêm ngặt:
1. **Từ chối (throw error) giá trị `undefined`**: Trường optional trong JS/TS hay gặp phải.
2. **Nghiêm cấm ký tự đặc biệt trong Object Key**: Các ký tự `. # $ / [ ]` tuyệt đối không được xuất hiện ở tên key (ví dụ tiêu đề tập `"Tập 1. Mở đầu"` từ nguồn API phim nếu dùng làm key sẽ làm crash toàn bộ lệnh ghi `ref.set()`).

Hàm `cleanFirebasePayload` trong `lib/firebaseAdmin.ts` đệ quy xử lý cả 2 vấn đề:

```typescript
export function cleanFirebasePayload<T>(obj: T): T {
  if (obj === null || obj === undefined) return null as any;
  if (Array.isArray(obj)) return obj.map(cleanFirebasePayload) as any;
  if (typeof obj === 'object') {
    const res: any = {};
    for (const key of Object.keys(obj as any)) {
      const val = (obj as any)[key];
      if (val !== undefined) {
        // Khử toàn bộ ký tự cấm của Firebase trong key: . # $ / [ ]
        const sanitizedKey = key.replace(/[\/\.\#\$\[\]]/g, '_');
        res[sanitizedKey] = cleanFirebasePayload(val);
      }
    }
    return res;
  }
  return obj;
}
```

## 🔑 4. Cơ Chế Khởi Tạo 3 Tầng Dự Phòng (Credentials Resolution)
Nằm trong `lib/firebaseAdmin.ts`, hàm `getFirebaseAdmin()` giải quyết vấn đề cấu hình môi trường một cách thông minh:
1. **Tầng 1 (Localhost)**: Đọc trực tiếp tệp `firebasekey.json` ở thư mục gốc nếu tồn tại.
2. **Tầng 2 (Vercel Khuyên Dùng)**: Đọc chuỗi JSON từ biến môi trường `FIREBASE_SERVICE_ACCOUNT_KEY`.
3. **Tầng 3 (Biến Riêng Biệt)**: Đọc 3 biến rời `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` và tự động khôi phục ký tự xuống dòng `\n`.
