## 📑 2. Đặc Tả Chi Tiết Từng Endpoint

### 2.1 `/api/logo` (GET)
- **Tham số Query**:
  - `title`: Tên phim chính.
  - `subTitle` *(optional)*: Tên phụ / Tên tiếng Anh.
  - `slug` *(optional)*: Mã slug của phim.
  - `tmdbId` *(optional)*: ID của phim trên TMDB (nếu có).
  - `year` *(optional)*: Năm sản xuất.
  - `mediaType` *(optional)*: `'movie'` hoặc `'tv'`.
- **Response thành công (200)**:
  ```json
  {
    "logoUrl": "https://image.tmdb.org/t/p/original/abcxyz.svg"
  }
  ```

---

### 2.2 `/api/trailer` (GET)
- **Tham số Query**: `title`, `subTitle`, `slug`, `tmdbId`, `year`, `type`.
- **Response thành công (200)**:
  ```json
  {
    "youtubeKey": "dQw4w9WgXcQ",
    "backupKeys": ["key2", "key3"],
    "source": "tmdb"
  }
  ```

---

### 2.3 `/api/auth/login` (POST)
- **Body**:
  ```json
  {
    "username": "tronglich",
    "password": "secretpassword"
  }
  ```
- **Xử lý**:
  - Tự động chuyển `username` về chữ thường (`toLowerCase()`).
  - So khớp mật khẩu với hàm `bcrypt.compare`.
  - Thiết lập cookie HttpOnly `lixfnet_session` có hạn 30 ngày.
- **Response thành công (200)**:
  ```json
  {
    "success": true,
    "user": {
      "username": "tronglich",
      "displayName": "Trọng Lịch",
      "role": "admin"
    }
  }
  ```

---

### 2.4 `/api/user/progress` (GET / POST / DELETE)
- **POST Body**:
  ```json
  {
    "key": "co-nang-ngu-ngoc",
    "progress": {
      "movieId": "co-nang-ngu-ngoc",
      "currentTime": 1250,
      "duration": 6000,
      "progressPercent": 20.8,
      "episodeTitle": "Tập 3",
      "updatedAt": 1792650000000
    }
  }
  ```
- **Xử lý**:
  - Tự động lấy tên người dùng từ cookie `lixfnet_session`.
  - Làm sạch các ký tự đặc biệt trong `key` trước khi lưu vào Firebase.
  - Ghi vào đường dẫn `lixfnet/users/{username}/watchProgress/{cleanKey}`.

### 2.5 `/api/user/mylist` (GET / POST / DELETE)
Đồng bộ danh sách xem sau (My List / Bookmark) của tài khoản:
- **GET**: Trả về toàn bộ danh sách phim đã lưu của user (`Movie[]`).
- **POST**: Thêm hoặc cập nhật một phim vào danh sách xem sau.
  - **Body**: `{ "key": "slug-hoac-id", "movie": { "id": "...", "title": "...", "posterUrl": "..." } }`
  - Ghi vào đường dẫn `lixfnet/users/{username}/myList/{cleanKey}`.
- **DELETE**: Xóa phim khỏi danh sách xem sau.
  - **Body**: `{ "key": "slug-hoac-id" }`
  - Gỡ bỏ node tương ứng trên Firebase Realtime Database.

### 2.6 `/api/netflix-top10` (GET)
Thu thập và chuẩn hóa dữ liệu bảng xếp hạng Top 10 của Netflix tại thị trường Việt Nam:
- **Nguồn Dữ Liệu**: Bóc tách (scrape & parse) trực tiếp từ trang chính thức Netflix Tudum (`https://www.netflix.com/tudum/top10/vietnam`) cho cả 2 danh mục:
  1. *Films (Phim lẻ tại Việt Nam)*
  2. *TV / Series (Phim bộ tại Việt Nam)*
- **Cơ Chế Bộ Nhớ Đệm (In-Memory Cache)**:
  - Dữ liệu Top 10 của Netflix chỉ cập nhật mỗi tuần 1 lần.
  - Endpoint thiết lập bộ nhớ đệm RAM với thời hạn **6 giờ** (`CACHE_TTL = 6 * 60 * 60 * 1000`). Mọi request trong vòng 6 giờ đều phản hồi tức thì với độ trễ 0ms, không tốn băng thông cào web.
- **Quy Trình Chuẩn Hóa & Đối Soát (Enrichment Flow)**:
  1. Bóc tách danh sách 10 phim kèm thứ hạng (Rank 1 - 10) và số tuần nằm trong top.
  2. Dọn sạch các hậu tố mùa rườm rà (ví dụ `: Season 1`, `: Limited Series`).
  3. Tra cứu từ điển chuẩn `NETFLIX_VN_TUDUM_DICTIONARY` để lấy TMDB ID và slug NguonC.
  4. Nếu chưa có trong từ điển, tự động query TMDB Multi-Search để lấy thông tin chi tiết (Title Logo, backdrop, overview, rating).
  5. Đối soát chéo với NguonC để lấy link stream phát phim và danh sách tập phim thực tế.
- **Response mẫu (200)**:
  ```json
  {
    "films": [
      {
        "id": "tho-oi-2024",
        "title": "Thỏ Ơi!",
        "subTitle": "Bunny!",
        "rank": 1,
        "isTop10": true,
        "platform": "netflix",
        "badge": "top10",
        "hasSource": true
      }
    ],
    "series": [
      {
        "id": "khong-the-thay-the-2026",
        "title": "Không Thể Thay Thế",
        "subTitle": "Irreplaceable",
        "rank": 7,
        "isTop10": true,
        "platform": "netflix",
        "badge": "top10",
        "hasSource": true
      }
    ],
    "updatedAt": "2026-10-22T16:00:00.000Z"
  }
  ```
