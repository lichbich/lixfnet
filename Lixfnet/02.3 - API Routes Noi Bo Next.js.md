## 📑 2. Đặc Tả Chi Tiết Từng Endpoint

### 2.1 `/api/logo` (GET)
- **Tham số Query**:
  - `title`: Tên phim chính.
  - `subTitle` *(optional)*: Tên phụ / Tên tiếng Anh.
  - `slug` *(optional)*: Mã slug của phim.
  - `tmdbId` *(optional)*: ID của phim trên TMDB (nếu có).
  - `year` *(optional)*: Năm sản xuất.
  - `mediaType` *(optional)*: `'movie'` hoặc `'tv'`.
- **Response thành công (200)**:
  ```json
  {
    "logoUrl": "https://image.tmdb.org/t/p/original/abcxyz.svg"
  }
  ```

---

### 2.2 `/api/trailer` (GET)
- **Tham số Query**: `title`, `subTitle`, `slug`, `tmdbId`, `year`, `type`.
- **Response thành công (200)**:
  ```json
  {
    "youtubeKey": "dQw4w9WgXcQ",
    "backupKeys": ["key2", "key3"],
    "source": "tmdb"
  }
  ```

---

### 2.3 `/api/auth/login` (POST)
- **Body**:
  ```json
  {
    "username": "tronglich",
    "password": "secretpassword"
  }
  ```
- **Xử lý**:
  - Tự động chuyển `username` về chữ thường (`toLowerCase()`).
  - So khớp mật khẩu với hàm `bcrypt.compare`.
  - Thiết lập cookie HttpOnly `lixfnet_session` có hạn 30 ngày.
- **Response thành công (200)**:
  ```json
  {
    "success": true,
    "user": {
      "username": "tronglich",
      "displayName": "Trọng Lịch",
      "role": "admin"
    }
  }
  ```

---

### 2.4 `/api/user/progress` (GET / POST / DELETE)
- **POST Body**:
  ```json
  {
    "key": "co-nang-ngu-ngoc",
    "progress": {
      "movieId": "co-nang-ngu-ngoc",
      "currentTime": 1250,
      "duration": 6000,
      "progressPercent": 20.8,
      "episodeTitle": "Tập 3",
      "updatedAt": 1792650000000
    }
  }
  ```
- **Xử lý**:
  - Tự động lấy tên người dùng từ cookie `lixfnet_session`.
  - Làm sạch các ký tự đặc biệt trong `key` trước khi lưu vào Firebase.
  - Ghi vào đường dẫn `lixfnet/users/{username}/watchProgress/{cleanKey}`.

### 2.5 `/api/user/mylist` (GET / POST / DELETE)
Đồng bộ danh sách xem sau (My List / Bookmark) của tài khoản:
- **GET**: Trả về toàn bộ danh sách phim đã lưu của user (`Movie[]`).
- **POST**: Thêm hoặc cập nhật một phim vào danh sách xem sau.
  - **Body**: `{ "key": "slug-hoac-id", "movie": { "id": "...", "title": "...", "posterUrl": "..." } }`
  - Ghi vào đường dẫn `lixfnet/users/{username}/myList/{cleanKey}`.
- **DELETE**: Xóa phim khỏi danh sách xem sau.
  - **Body**: `{ "key": "slug-hoac-id" }`
  - Gỡ bỏ node tương ứng trên Firebase Realtime Database.
