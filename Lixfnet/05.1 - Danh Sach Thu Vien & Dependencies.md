## 🔍 2. Vai Trò Từng Thư Viện

### 2.1 `next` (v16.4.2)
- Framework nền tảng cung cấp kiến trúc **App Router**.
- **Turbopack tích hợp**: Biên dịch code siêu tốc trong môi trường dev (`next dev --turbopack`) và tối ưu hóa gói bundle production khi build (`next build`).
- **Server Actions & Route Handlers**: Xử lý toàn bộ logic API nội bộ (`/api/*`) mà không cần dựng thêm backend Express.js riêng biệt.

### 2.2 `react` & `react-dom` (v19.3.0)
- Phiên bản React mới nhất hỗ trợ các hooks hiện đại (`useActionState`, `useOptimistic`), tối ưu hóa render bất đồng bộ và khả năng tương thích trọn vẹn với Next.js 16.

### 2.3 `tailwindcss` (v4) & `@tailwindcss/turbopack`
- Thế hệ Tailwind CSS v4 hoàn toàn mới: Cấu hình trực tiếp trong CSS (`@theme`), tốc độ render vượt trội, không cần tệp `tailwind.config.js` cồng kềnh.
- Hỗ trợ xây dựng giao diện Netflix mượt mà với các class tiện ích linh hoạt.

### 2.4 `lucide-react` (^1.60.0)
- Bộ icon đồ họa vector tinh xảo: `Play`, `Pause`, `RotateCw`, `ListVideo`, `Volume2`, `VolumeX`, `Maximize`, `Minimize`, `ArrowLeft`, `Check`, `Plus`, `Search`, `Info`.
- Tự động tree-shaking giúp kích thước bundle nhỏ nhất có thể.

### 2.5 `firebase-admin` (^14.5.0)
- Thư viện chính thức từ Google Firebase để truy cập an toàn vào **Firebase Realtime Database** từ môi trường server-side của Next.js với đầy đủ quyền quản trị.

### 2.6 `bcryptjs` (^3.0.3)
- Thư viện băm và kiểm tra mật khẩu bằng thuật toán Blowfish. Hoạt động 100% bằng JavaScript thuần, không phụ thuộc vào C++ binding của hệ điều hành, đảm bảo chạy trơn tru cả trên Windows, macOS, Linux và môi trường Vercel Serverless.
