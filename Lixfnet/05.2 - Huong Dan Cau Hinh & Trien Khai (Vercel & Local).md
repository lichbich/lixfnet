## 💻 1. Chạy Dự Án Ở Máy Cá Nhân (Localhost)

1. **Cài đặt thư viện**:
   ```bash
   npm install
   ```
2. **Khóa Firebase**:
   - Đảm bảo tệp `firebasekey.json` nằm ở thư mục gốc của dự án (`netlix/firebasekey.json`).
   - Hệ thống sẽ tự động nhận diện tệp này mà **không cần cấu hình thêm bất kỳ biến môi trường nào**.
3. **Khởi chạy máy chủ phát triển**:
   ```bash
   npm run dev
   ```
   - Truy cập vào: `http://localhost:3000`
   - Đăng nhập với tài khoản Admin mặc định:
     - **Tài khoản**: `tronglich`
     - **Mật khẩu**: `389363`

## ☁️ 2. Triển Khai Lên Vercel (Production Cloud)

### 2.1 An Toàn Mã Nguồn Trên GitHub
- Tệp `.gitignore` đã được cấu hình chặn tự động:
  - `firebasekey.json`
  - `.env.local`
- **Tuyệt đối không bao giờ push private key lên GitHub** để tránh bị quét lộ thông tin bảo mật.

### 2.2 Cấu Hình Biến Môi Trường Trên Vercel
Khi import dự án vào Vercel (vào **Project Settings $\rightarrow$ Environment Variables**), thiết lập các biến sau:

| Tên Biến Môi Trường | Giá Trị Cần Điền | Ghi Chú |
| :--- | :--- | :--- |
| `FIREBASE_SERVICE_ACCOUNT_KEY` | *(Toàn bộ chuỗi JSON trong file `firebasekey.json`)* | **Khuyên dùng nhất** (Đầy đủ và tiện lợi) |
| `FIREBASE_DATABASE_URL` | `https://unichat-acfc2-default-rtdb.firebaseio.com` | URL Realtime Database |
| `TMDB_API_KEY` | `58dba4066f4f36e49e5e769304442088` | Key lấy trailer YouTube & Title Logo |
| `TMDB_READ_ACCESS_TOKEN` | *(Chuỗi JWT Access Token của TMDB)* | Hỗ trợ tìm kiếm mở rộng |

### 2.3 Lệnh Kiểm Tra Build
Trước khi push code, luôn chạy thử lệnh build để đảm bảo TypeScript không có lỗi cú pháp:
```bash
npm run build
```
Kết quả thành công sẽ hiển thị mã thoát `exit code 0` và danh sách các static/dynamic routes.
