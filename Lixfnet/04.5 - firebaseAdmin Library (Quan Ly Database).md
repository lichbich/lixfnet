## 🏛️ 1. Giới Thiệu `lib/firebaseAdmin.ts`
Tệp `lib/firebaseAdmin.ts` là module máy chủ (Server-only Library) quản trị toàn bộ kết nối và các thao tác đọc/ghi vào **Firebase Realtime Database**.

---

## 🔌 2. Khởi Tạo Singleton: `getFirebaseAdmin`

Để tránh việc khởi tạo lại nhiều app Firebase trùng lặp mỗi khi có request trong môi trường Serverless của Next.js:

```typescript
let appInstance: App | null = null;
let dbInstance: Database | null = null;

export function getFirebaseAdmin(): { app: App; db: Database } {
  // Trả về instance đã có sẵn trong bộ nhớ cache
  if (appInstance && dbInstance) {
    return { app: appInstance, db: dbInstance };
  }

  // Tận dụng instance đã được khởi tạo bởi Firebase Admin
  const existingApps = getApps();
  if (existingApps.length > 0) {
    appInstance = existingApps[0];
    dbInstance = getDatabase(appInstance);
    return { app: appInstance, db: dbInstance };
  }

  // ... Đọc credentials theo 3 tầng ưu tiên ...

  appInstance = initializeApp({
    credential: cert(serviceAccount),
    databaseURL,
  });

  dbInstance = getDatabase(appInstance);
  return { app: appInstance, db: dbInstance };
}
```

## 🛠️ 3. Danh Sách Các Hàm CRUD Chính

### 3.1 Nhóm Quản Trị Người Dùng (Users)
- `findUser(username)`: Tìm kiếm tài khoản trong `lixfnet/users/{cleanUsername}`.
- `saveUser(userData)`: Thêm mới hoặc cập nhật thông tin tài khoản.
- `listUsers()`: Lấy danh sách toàn bộ người dùng (tự động loại bỏ trường `passwordHash` để bảo mật).
- `deleteUser(username)`: Xóa tài khoản vĩnh viễn khỏi hệ thống.

### 3.2 Nhóm Quản Lý Tiến Trình Xem (Watch Progress)
- `getUserWatchProgress(username)`: Lấy toàn bộ lịch sử xem của người dùng.
- `saveUserWatchProgress(username, key, progressData)`:
  - Làm sạch `key` bằng regex: `key.replace(/[\/\.\#\$\[\]]/g, '_')`.
  - Làm sạch payload bằng `cleanFirebasePayload(progressData)`.
  - Ghi vào `lixfnet/users/{username}/watchProgress/{cleanKey}`.
- `removeUserWatchProgress(username, key)`: Xóa một tựa phim khỏi lịch sử xem.
